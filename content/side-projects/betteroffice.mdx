The office engine for the agent era.

## What it is

- OOXML-native engine for docx, xlsx & pptx: no format conversion, no fidelity loss
- Rust core, built to be driven by AI agents
- Compiles to WASM, so it runs anywhere, including directly in the browser
- Editing, rendering and real-time collaboration

## Open source

- Fully open source on [GitHub](https://github.com/openooxml/betteroffice)
- Ships to npm, crates.io and PyPI
- Used by OpenCode, among others
