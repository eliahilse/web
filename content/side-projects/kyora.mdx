Software engineering at agent scale.

## What it is

The harness and infrastructure to run, coordinate and observe fleets of coding agents, on the subscriptions you already pay for.

## VMs

- Throwaway Firecracker microVMs for agents: upload a worktree, run anything, stream the output, destroy
- Billed per second, roughly 40% cheaper than comparable sandbox providers
- Suspend & resume, snapshots, fork & reset, live migration while running
- Regions in the EU, US and APAC

## Harness

- **review**: Codex, Claude Code, OpenCode, Grok, GLM, Qwen and Kimi review the same diff, consensus-ranked
- **council**: MCP server that lets an agent ask other model families for a second opinion, or hand them work
- **state**: records an app's state changes, calls, HTTP traffic and errors so agents can query them over MCP
- **switch**: hot-swap Claude Code, Codex and OpenCode logins with live quota
